# Textures — Procedurally generated

The `parchment-2k-warm.jpg`, `parchment-2k-vignette.jpg`, and `parchment-1k-tile.jpg` files in this folder are **CC0 / Public Domain** procedurally generated by ImageMagick (multi-octave noise + warm sepia tone + edge vignette). No external assets used.

Older experimental files (`parchment-tile-*.png`, `p-*.png`, `apprentice-*.png`, `corner-ornament-*.png`, `scroll-cap-*.png`) are also procedurally generated CC0.

## Recipe (parchment-2k-warm.jpg)

```bash
convert -size 2048x2048 xc:'#e8d5a8' \
  \( -size 2048x2048 xc: +noise random -channel R -separate +channel \
     -blur 0x2 -level 30%,80% -modulate 100,30,80 \) \
  -compose multiply -composite \
  \( -size 2048x2048 xc: +noise random -blur 0x6 -level 40%,90% \
     -modulate 100,15,75 -evaluate multiply 0.85 \) \
  -compose multiply -composite \
  \( -size 2048x2048 xc: +noise random -blur 0x12 -level 60%,100% \
     -modulate 100,10,70 \) \
  -compose multiply -composite \
  -modulate 105,90,85 \
  -attenuate 0.4 +noise gaussian \
  parchment-2k-warm.png

convert parchment-2k-warm.png -quality 78 -strip parchment-2k-warm.jpg
```

Anyone can re-generate / re-tone these freely. No license restrictions.
