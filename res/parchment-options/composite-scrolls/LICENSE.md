# Composite Scroll Backgrounds — Sources & Licenses

5 high-fidelity composite scroll mockups, all **CC0** (created by us via ImageMagick combining real public-domain assets + procedural generation).

## Composition Recipe (per file)

Each scroll is a vertical composition of these layers, top to bottom:
1. **Wood handle (top)** — radial gradient brown `#7a4a1a → #2c1606` + Gaussian noise (faking cylinder lighting, mimics carved wood scroll axis)
2. **Brocade strip** — cropped 32px slice of `cn-real-03-gold-fabric.jpg` (Wikimedia PD: golden Chinese fabric texture)
3. **Procedural xuan paper** — `#fbf6e7` cream base + Gaussian noise + slight blur (blank rice paper feel)
4. **Brocade strip** (mirrored)
5. **Wood handle (bottom)** (mirrored)

Variants:
- `c1-vertical-scroll.jpg` (518K) — full layout, **70px wood handles**
- `c2-vertical-minimal.jpg` (278K) — no wood, just dark red bands + thin brocade
- `c3-horizontal-handscroll.jpg` (431K) — horizontal handscroll, full wood handles
- `c4-horizontal-thin-handles.jpg` (405K) — horizontal, thin 36px wood ends
- `c5-vertical-thin-handles.jpg` (478K) — vertical with elegant 36px thin handles
