Letter Style Picker · 信笺刻印

6 ways to make text feel like it belongs on the parchment — using text effects, not background highlights. Each style is one cohesive "letter":
different parts of the same passage get different surface treatments (letterpress, gold leaf, iron engraving, wax seal, watercolor wash).
All 6 share the same parchment background and handwritten font.

№ 1

Quill Letter  ·  鹅毛笔信

Pure flat ink. No tricks. The most authentic "just written" feel — like a recently dried letter.

tech: solid sepia color only · headings + body same ink, links underlined, "key terms" via dotted underline + bold

№ 2

Pressed Manuscript  ·  凸印手稿

Hero name raised off the page (embossed). Body text sunken in (debossed/letterpress). Key terms chiseled into the page.

tech: text-shadow inset + light highlight + dark depth · CSS letterpress / emboss · subtle relief, no animation

Gilded Page  ·  烫金页 ★

Iron Engraved  ·  铁版镌刻

Hero name in cold steel chiseled into the page. Key terms deeply engraved (gray-dark with sharp shadow). Most architectural / serious.

tech: cool gray tones + sharp text-shadow stack · darker top + lighter bottom = chisel illusion · no chroma, all about depth

All text in sepia ink. Key terms get a soft watercolor wash swept under them — readable, parchment-toned, painterly.

tech: linear-gradient bg under text · ochre wash, transparent edges, blends with parchment · NOT a flat highlight bar

选一个编号告诉我，例如 "用 № 3 Gilded Page"。我把对应的 text-effect stack 接到 parchment-overrides.css。也可混搭：如 "名字用 № 3 烫金，body 用 № 1 鹅毛笔，highlight 用 № 2 凸印"。

所有效果都用纯 CSS 实现：
text-shadow · background-clip:text · linear-gradient · filter:drop-shadow
无背景色块，无图片素材依赖，文字全部直接落在羊皮纸上。
