## 为何归档

旧版 "About Me" 渲染为四段长文（`locales/*.json` 中的 `about.p1` … `about.p4`）。招聘方扫读时这种段落形式读起来慢，亮点会被埋住。2026-04-24 改版替换为：

- 一句强标题（`about.headline`）
- 六条带 emoji 与加粗关键词的短项（`about.b1` … `about.b6`）
- 第七条 "求职方向" 项（`about.b7`）

旧的四段文字本身写得不错，归档于此，方便日后写求职信、与招聘方沟通、或者将来扩出独立 About 页时再用。
