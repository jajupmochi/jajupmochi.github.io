Blog 手写纸拟物化设计实验室

每个 Markdown 模块给出 3 种拟物设计（实物部件：手稿 · 古文献 · 手写信 · 书籍 · 卷轴 · 魔法书）。在羊皮纸背景上并排对比，选你喜欢的我再落地到博客。

交互演示：② 目录开关可点击卷起/展开 · ① 阅读进度自动循环。其余为静态样式预览。

①进度②开关③滚动条④引用⑤代码块⑥表格⑦列表⑧标题⑨分隔线

① 阅读进度（墨痕）

顶部细线 → 真实墨迹感。三种：毛笔墨带 / 墨滴渗染 / 卷轴展卷。

② 目录开关（三角 → 镇纸 / 别针 / 系带）

点击任一演示，卷轴卷起或展开。

③ 目录侧边滚动条（拟物化卷轴部件）

不只是变色——做成卷轴真实会有的部件。静态预览（落地时为可拖拽）。

④ 引用（blockquote）

从竖线框 → 实物便签 / 页边批注 / 朱砂引文。

⑤ 代码块

语言标签 + 复制保留；外形拟物：稿纸 / 打字机纸条 / 小卷轴。

⑥ 表格

从硬网格 → 账本红线 / 手绘墨格 / 卡片分栏。

⑦ 列表 / 项目符号

从默认圆点 → 手绘墨点 / 朱砂花饰 / 引导线+指示手。

⑧ 标题

复用主页泥金首字母；另出朱批 + 书签页两式。

⑨ 分隔线

从虚线 → 飞白墨线 / 花饰星标 / 纸张折痕。
