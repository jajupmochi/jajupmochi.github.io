Blog code-block scrollbar options

Each box is the blog's parchment code block (warm cream, torn-corner radius). The first uses the current default browser scrollbar (the clash); the next four are parchment-matched. Both axes scroll. Pick one.

0 · Default (current)

Standard OS/browser scrollbar — gray, square, off-palette.

def transfer_ratio(graph, kernel):  # a deliberately long line to force horizontal scrolling on the parchment slip
    K = compute_gram_matrix(graph, kernel)        # gram matrix
    pre = preimage(K, target, method="iterative") # 预映射
    return score(pre) / score(target)
